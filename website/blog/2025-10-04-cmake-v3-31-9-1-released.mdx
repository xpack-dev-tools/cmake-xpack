<PageMetadata title={frontMatter.seo_title} />

The [xPack CMake](https://xpack-dev-tools.github.io/cmake-xpack/)
is a standalone cross-platform binary distribution of
[CMake](https://cmake.org).

There are separate binaries for **Windows** (x64),
**macOS** (x64 and arm64)
and **GNU/Linux** (x64 and arm64).

:::note Raspberry Pi

The main targets for the GNU/Linux Arm
binaries are the **Raspberry Pi** class devices (aarch64 only;
armv6 and armv7l are no longer supported).

:::

## Download

The binary files are available from <a href={frontMatter.download_url}>GitHub Releases</a>.

## Install

The easiest way to install this specific version, is by using **xpm**:

<CodeBlock language="console"> {
`xpm install @xpack-dev-tools/cmake@${frontMatter.version}.${frontMatter.npm_subversion} -verbose
`} </CodeBlock>

Comprehensive instructions for installing **xPack CMake** on different platforms
can be found in the [Install Guide](/docs/install/).

## Compliance

The **xPack CMake** is based on the official
[CMake](https://cmake.org), with no changes.

The current version is based on:

- CMake release
[{frontMatter.cmake_version}](https://github.com/Kitware/CMake/releases/tag/v{frontMatter.cmake_version}/) from {frontMatter.cmake_release_date}.

## Changes

- none

:::tip

Starting with mid-2024 (v3.28.6-1), the patch to spawn processes on Windows via `cmd.exe /c` was no longer applied. The direct consequence is applications started via `.cmd` shim need to declare the `.cmd` extension explicitly (like `ninja.cmd`).

:::

## Build

The binaries for all supported platforms
(Windows, macOS and GNU/Linux) were built using the
[xPack Build Box (XBB)](https://xpack.github.io/xbb/), a set
of build environments based on slightly older distributions, that should be
compatible with most recent systems.

For the prerequisites and more details on the build procedure, please see the
[Maintainer Info](/docs/maintainer/) page.
